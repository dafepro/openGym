# 013 — Editable StrongLifts templates

Offer StrongLifts 5×5 and a three-set variation in the starter chooser. Both create two local routines in an editable 12-week programme. Starting it is a separate action. Use the existing rotation to alternate A/B across weeks, with one rest day between sessions and two after every third session. A missed session waits its turn.

Use the squat, bench press and row in A, and the squat, overhead press and single work set of deadlifts in B. Let the lifter set starting weights, rest and progression in the routine editor. The [StrongLifts guide](https://stronglifts.com/stronglifts-5x5/workout-program/) describes the base schedule.
