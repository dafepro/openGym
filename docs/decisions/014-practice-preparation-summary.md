# 014 — Practice preparation before Start

Accepted 2026-11-16. The owner requested another high-priority UX improvement
while separate agents handle assignments/deployment and offline recovery.

Show a compact preparation summary before Start on assigned/shared practice
previews and expanded saved/recent practices. Use supplied prescriptions and
structured drill metadata for time, equipment, space, participants and focus.
Keep Start a direct action; preparation does not add a confirmation screen.

Timed work includes sets, both feet and prescribed rests between rows, but no
rest after the final row. Label setup and open-ended work separately. Never
estimate rep cadence, self-paced duration or missing setup requirements. Mark
partial equipment lists and missing metadata explicitly. A spatial envelope may
rotate each listed rectangle; incompatible participant ranges vary by drill.
Video review remains distinct from athletic work. Existing notes and instructions
remain available, including prose-only setup that cannot be summarized reliably.

Home actions distinguish Create practice, Import practice and Create drill.
Keep the existing routes and editing behavior. No new content fields, storage,
authentication, automatic notifications or infrastructure are introduced.

Coach compiler enrichment of structured setup remains follow-up work; this UI
must remain truthful for older practices and user-created drills without it.
