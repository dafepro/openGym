# 019 — Purposeful Playbook controls and regression coverage

Accepted 2026-11-16 following the owner's review criteria. Keep visible words only
when they convey a decision, consequence, data value or recovery action that the
visual state cannot convey. Prefer recognizable icons, state indicators and brief
transitions for navigation, loading, selection and completion. Preserve accessible
names and reduced-motion behavior; privacy consent, unknown preparation needs,
research costs and irreversible publishing consequences must remain explicit.

Use the existing practice runner and local history. Assignment and coach review
features may add context and explicit sharing, not a competing session engine.
Broader consolidation of assignments, library entry points and experimental
camera practice is tracked separately. Keep experimental camera training held
until integration and physical-device qualification are complete.

Tests protect observable behavior and meaningful risks: consent boundaries,
actual-work preservation, recovery, publishing authority and browser-resource
cleanup. Remove unused-feature tests and avoid assertions that freeze component
structure, incidental wording or a particular implementation. Keep useful motion,
keyboard and layout checks; new decorative changes do not need mirror tests.
