# 016 — Full-screen night ball overlay

Supersedes ADR 015 presentation and controls. The owner requested a full-screen
faded dark background with luminous goals and scores inside the goals, without a
pitch drawing, visible copy, menus or directional buttons. Remove phone tilt and
all sensor permission handling. Drag the ball to kick; tap it again to fade the
overlay away and restore the app. Escape also closes it. Scores remain in memory
for the current home-screen visit. The underlying app is inert while playing.
