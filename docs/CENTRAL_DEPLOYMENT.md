# Uplift production build and promotion

The production source branch is `codex/focused-workout-overlay`. Its push-triggered `worker-release.yml` defaults trusted builds to the registered Mac; setting `BUILD_RUNNER=github` selects hosted Ubuntu. It verifies the frontend, locale/source strings, Garmin Worker and static-only delivery contract, then packages prebuilt Worker/assets under a retained GitHub release. PR #1 also brought Uplift into `main`; keep both branches synchronized while this release workflow remains attached to the established source branch (ADR 009).

Repository variable `DEPLOY_REQUESTS_ENABLED=true` enables publication/request only. `DEPLOY_REQUEST_TOKEN` is a fine-grained Issues-write-only token on private `dafepro/deploy`; this public repository receives no Cloudflare deployment token. Cloud deployment occurs only after manual review and merge of the shared Uplift target's release PR in deploy.

openGym is the sole source for the existing Uplift Worker, custom domain, Garmin Durable Object identity/migration and rate-limit namespaces. The original `dafepro/uplift` app is retired as a build and rollback source. Its legacy controller remains available only until cutover: disable both `deploy.yml` and `release-uplift-fork.yml` before enabling central deployment, then archive the original repo after central deployment and live qualification pass. Follow [central cutover](https://github.com/dafepro/deploy/blob/main/docs/cutover.md); preserve both apps' browser/Drive storage and existing Garmin pairing policy.

This workflow intentionally has a push trigger: GitHub manual dispatch requires a workflow on the default branch, while upstream `main` is not this fork's production source. Publishing does not auto-promote a release. Real-device and synthetic live Garmin protocol qualification remain release requirements.
