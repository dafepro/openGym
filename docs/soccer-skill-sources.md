# Soccer technique starter library: editorial record

Reviewed 2026-10-30. The ten sessions in `training/src/data/skill-workouts.js` are original, public starter practices for general beginner/youth use. They are not trainer assignments or age-specific prescriptions. They do not imply federation endorsement. A source's age-group title does not identify the user's age.

The linked primary coaching sources support technique ideas. The layouts, reduced participant counts, short blocks, suggested repetitions, rests, and unopposed adaptations are editorial defaults, not extracted training prescriptions or evidence of an optimal dose. Pace is light to moderate, with extra rest permitted. No heading, tackling, body contact, maximal sprints, punishment exercises, or injury-prevention promises are prescribed.

## Content and counting decisions

- Every session has four usable blocks with setup, actions, and an explicit focus sentence. Warm-up blocks start with gentle skill movement; final blocks finish gently where practical. Shooting and weaker-foot repetition blocks include walking retrieval.
- Only two shooting blocks use `side: 'each'`: the app schedules the stated count for each foot. All other blocks use `side: 'both'`; alternating-foot and weaker-foot-only instructions are part of that single block, not doubled work.
- Time-block role changes are inside the stated duration. When a set count matches the number of players, instructions rotate the central role once per set. These are session blocks rather than a separate prescribed dose for each participant.
- Participants are exact: solo = one; partner = two; scanning = three. Roles are empty because no specialist coach, goalkeeper, or other qualified role is required; ordinary player roles rotate in the instructions.
- Equipment metadata lists item types; instructions supply quantities and geometry. Indoor-compatible sessions require a clear suitable playing surface and the specified space. Shooting and defending are outdoor-only.
- All 40 media entries are explicitly unavailable. External coaching pages may contain videos, but no video is downloaded, embedded, licensed, or marked as approved by this module.
- Existing canonical tags cover the library; no registry extension is required.
